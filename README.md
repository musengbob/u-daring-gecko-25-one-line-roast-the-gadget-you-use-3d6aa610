One original line roasting the gadget I use every day — my wireless earbuds — written for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty. `main.ts` writes the line (143 code points, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` and verifies it by reading it back byte-for-byte.

> My earbuds cost more than my first car payment and still pop out every time I sneeze — expensive confetti with Bluetooth and commitment issues.

## Run it

```sh
node main.ts
```
